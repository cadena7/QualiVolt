# Archivos de prueba

Esta carpeta conserva las dos grabaciones originales HT PQA820 (pares HED/PER), sus reportes de configuración exportados por TopView y el registro histórico `binary_validation.json`.

Para probar la app, abre cualquiera de los archivos `.HED` de esta carpeta. Su archivo `.PER` debe permanecer junto a él.

Las pruebas buscan aquí los pares binarios. Si se añaden los CSV de referencia con los mismos nombres, también comparan todos sus valores y fechas. Los CSV no están presentes actualmente: el JSON documenta comparaciones anteriores y no sustituye volver a ejecutarlas con sus archivos de referencia.

Estas grabaciones contienen datos reales de mediciones y se incluyen como ejemplos del proyecto por indicación de su autor.
