# Geist Sans 1.8.2

Fuente del proyecto Vercel Geist. Archivos originales sin modificar:

- `Geist-Regular.ttf`: interfaz, cuerpo del informe, tablas y ejes.
- `Geist-SemiBold.ttf`: títulos.
- `Geist-Bold.ttf`: resultados destacados y negritas.

Origen: https://github.com/vercel/geist-font/releases/tag/v1.8.2

Distribuidos bajo SIL Open Font License 1.1; conservar `OFL.txt` y `LICENSE.txt`.
QualiVolt carga las fuentes localmente sin instalarlas en el sistema ni realizar descargas al ejecutar la app.
